# Bus Booking System

Mini Web Application developed according to the uploaded FSWD experiment requirements.

## Technologies
HTML, CSS, JavaScript, Node.js, Express.js and JSON.

## Features
- Landing/Home page
- User registration
- JSON-based persistent user storage
- Login with username/email and password validation
- Bus search by source and destination
- Bus booking with passenger details and seat count
- Booking history
- Logout

## Run
1. Install Node.js.
2. Open a terminal in this project folder.
3. Run:
   npm install
4. Run:
   npm start
5. Open:
   http://localhost:3000
